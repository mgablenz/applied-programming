"Most People Die Within Close Proximity of Where They Were Born"

An applied programming project in Python that tests the claim in the title using census data.

Taking Wikidata data of people born in Switzerland this program is calculating the distance of birthplace and deathplace.
In the next steps it visualizes the data using openmaps.

The goal is to:
- Make a reliable statement on the average distance between place of birth and place of death.
- Analyze how this relation changes within the trinational area Switzerland – Germany – France.
- Compare the results with the rest of Europe.
